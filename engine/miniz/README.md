# miniz (inflate only)

`tinfl`, the inflate part of [miniz](https://github.com/richgel999/miniz) by Rich Geldreich
(MIT licence, `LICENSE`), for the PNG station logos (`pva_png.c`): `miniz_tinfl.c/h` and
`miniz_common.h` as they are; `miniz.h` and `miniz_export.h` are small stand-ins (no malloc,
files or time).
